# ForAi Tap — Киберпанк Кликер

Полноценное, готовое к продакшену веб-приложение в жанре кликер (tap-game) с футуристичным дизайном в стиле киберпанк, системой прокачки, заданиями, ежедневными бонусами, случайными кибер-дропами, расчетом офлайн-дохода и интеграцией с Telegram Mini Apps (Telegram WebApp SDK).

## Возможности

- **Интерактивное энергетическое ядро:** Анимированный элемент управления с неоновым свечением, эффектом нажатия (`scale`), всплывающими анимированными числами наград (`+N`) и поддержкой тактильного отклика (Haptic Feedback).
- **Динамическая система энергии:** Ограничение максимального запаса энергии с постепенным восстановлением в реальном времени.
- **Прокачка и улучшения:** Четыре типа улучшений с динамическим ростом стоимости и эффекта:
  - *Мощность тапа* — увеличивает количество монет за одно нажатие.
  - *Ёмкость аккумулятора* — увеличивает максимальный запас энергии.
  - *Регенерация энергии* — ускоряет восстановление энергии в секунду.
  - *ИИ-Автотапер* — обеспечивает пассивный доход монет в секунду.
- **Ежедневные бонусы (Daily Rewards):** Получайте ценные награды за ежедневный вход в игру с трекером дней.
- **Кибер-дропы (Cyber Drops):** Случайные контейнеры, появляющиеся на игровом экране, при клике на которые активируется временный бонус (x2 к монетам за тап на 10 секунд) или мгновенная выплата.
- **Система уровней и опыта (XP):** Прогресс-бар уровня, заполняющийся при тапах и пассивном доходе.
- **Миссии и задания:** Интерактивные задачи с возможностью получения ценных наград.
- **Детальная статистика:** Окно с подробными метриками игровой сессии.
- **Офлайн-доход:** Автоматический расчет пассивного заработка за время отсутствия игрока (до 8 часов).
- **Интеграция с Telegram WebApps:** Автоматическое определение Telegram SDK, настройка шапки и тактильный отклик.
- **Сохранение прогресса:** Надежное сохранение всех данных игрока в `localStorage`.

## Структура файлов

Проект реализован на чистых технологиях HTML5, CSS3 и JavaScript без необходимости использования сборщиков, npm-модулей и внешних графических файлов (вся графика создана с помощью CSS и встроенного SVG):

```text
├── index.html        # Главная страница, структура HUD, игровые зоны и вкладки
├── css/
│   └── style.css     # Стили приложения: темный киберпанк дизайн, неоновые тени, анимации
├── js/
│   └── app.js        # Игровая логика, цикл, расчеты энергии, дропы, задания и Telegram SDK
└── README.md         # Документация проекта на русском языке
```

## Как запустить локально

1. Скачайте или клонируйте репозиторий проекта.
2. Откройте файл `index.html` в любом современном браузере (Chrome, Safari, Firefox, Edge).
3. Для корректной работы рекомендуется использовать локальный веб-сервер (например, расширение *Live Server* в VS Code).

## Деплой

Приложение является полностью статическим (`static`), поэтому его можно развернуть за пару минут на любом хостинге статических сайтов:
- **GitHub Pages:** Загрузите файлы в корневой каталог репозитория и включите Pages в настройках.
- **Vercel / Netlify:** Импортируйте проект или перетащите папку в панель управления.
- **Telegram Mini App:** Укажите полученный HTTPS-адрес вашего сайта в настройках бота через `@BotFather`.
